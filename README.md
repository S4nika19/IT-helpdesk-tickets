# IT Helpdesk Tickets 🎫

A simple IT helpdesk ticket system that runs in the browser.
Users can report an IT problem, and the support team can track each ticket until it is solved.

**Try it live:** https://s4nika19.github.io/it-helpdesk-tickets/

## Features
- Create a ticket with name, category (Laptop, Printer, Wi-Fi, Email, Password …), priority and description
- See all tickets in a list with their status
- Mark tickets as **solved** or open them again
- Filter tickets: All / Open / Solved
- High-priority tickets are highlighted
- Tickets are saved in the browser (localStorage), so they stay after a reload

## Built with
HTML · CSS · JavaScript (no frameworks)

## How to run
Open `index.html` in any web browser. No installation needed.

## Files
- `index.html` – page structure (form and ticket list)
- `style.css` – design
- `script.js` – logic (create, show, filter and solve tickets)
